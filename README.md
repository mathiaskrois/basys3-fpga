# Basys 3 FPGA projects

Projects for the Digilent Basys 3 (Xilinx Artix-7 XC7A35T), built with the
open-source openXC7 toolchain (yosys + nextpnr-xilinx) on macOS. No Vivado
needed.

| Project | What it is |
|---|---|
| [logic-analyzer](logic-analyzer/) | 8-channel, 100 MS/s USB logic analyzer that works with PulseView / sigrok |
